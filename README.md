# puntoDeVentaBackend

API RESTful para Sistema de Punto de Venta (POS Restaurante).

- **Entorno:** Node.js + TypeScript + Express + Prisma ORM
- **Base de Datos:** TiDB Cloud Serverless (MySQL 8)
- **Almacenamiento Cloud:** Google Cloud Storage (Bucket `punto_de_venta`)
- **Hosting Producción:** Render.com
- **CI/CD:** Webhook automatizado vía Render Deploy Hook en branch `master`
